# 论文视觉讲解与 Paper2Story

仅在制作视频讲稿、互动故事、视觉呈现或实际 Paper2Story 项目时加载。普通聊天和文章无需 scene、beat、逐 cue 或 harness 验收。

## 身份开场与认知连续性

Tao 的论文视频偏好：从真实首页交代团队、题名和贡献，随后用 Introduction 与 Related Work 讲清问题动机、已有研究路线、缺口和本文位置，再展开必要定义与方法。2026-09-21 起取消全片以单一案例为引线的要求；按需使用局部例子。身份定位和视觉转场均不能替代研究脉络。

复用用户已认可的表达方式，按新论文重新核源；不把旧片的秒数、章节数或具体结论套到新片。制作和发布走实际主机/项目工作流；Hermes 中已安装 video-router 时由该入口协调，其他主机不假定该工具存在。本参考不授予额外操作权限。

## Scene 与讲解节奏

- 一个 scene 回答一个核心问题，标题和问题连起来应构成论证路线。
- 机制场可以长，桥接场可以短；不平均分配篇幅。单句定义通常并入相邻解释，过多不同问题则拆开。
- 局部使用原文定位、关系解释和意义说明推进；只有条件改变结论含义时才补限定，不逐段添加否定句。
- 同一证据反复使用应推进新的理解；仅把一句话切成多拍时合并。
- 结果的定义、比较规则和局部限制出现在读者需要的位置，不能用节奏或装饰过渡填补解释缺口。

## 视觉表达

优先使用能解释问题的原论文图表、公式或当前页面；需要时制作准确表达结构、数量、状态变化的自制图。视觉应支持当前论点，不为填空提前搬来尚未解释的后文方法图。

- 定量比较展示尺度、单位、对照与范围，不能只播报数字。
- 原文中的并行、汇合和离线/在线边界保持真实；并列观测不能画成因果箭头。
- 在支持 visual 字段的实际项目中，visual: null 可保留完整叙述为主体，正文应即时可见并具有主视觉层级。
- 连续关键结果均无视觉承载时，检查是否丢失了趋势或比较；不能仅凭空视觉字段自动判失败。
- 隐藏旁白后视觉仍准确，隐藏视觉后叙述仍完整；字幕、数字、标记均由当前证据支持。

## 严格阅读器与真实 harness

上游配套故事发布能力不能假定在本机存在。只有项目实际提供 Document IR、sourceOrder、scene-local claims、validator 等接口时，才检验对应协议。

严格 PDF 阅读器/划线视频 profile 按 code-owned sourceOrder 单向推进，同页也不回退。普通研究笔记允许回引早先定义。源序正确不等于解释依赖正确，仍需核对定义和前置是否已建立；引言结果 preview 标为预告，主体解释在对应结果位置展开。

真实 staged harness 中各阶段的内容职责：

| 阶段 | 内容职责 |
|---|---|
| Evidence | 覆盖 Introduction、相关研究路线及本文定位、方法、设置、结果和结论；短引保留上下文，缺证据回原文补读。 |
| Argument plan | 先形成研究问题、已有路线与贡献关系、前置知识和机制，再安排场景；例子只承担局部解释。 |
| Story | beat 表达已核实的主张，不补事实；视觉由当前场景证据支持，避免机械拆拍。 |
| Review | 确定性 validator 检查源序等代码不变量；独立内容 reviewer 检查语义和认知连续性。 |

## 内容与视觉分别验收

完整讲稿的独立 reviewer 需拿到成稿、指定版本原文、图表与证据，分别检查事实支持和认知连续性。仅审数字、引文字符串或提纲不等于整稿通过。

影响理解或真实性的问题需修复：研究背景或相关工作实质缺失，方法动机跳步，使用的局部例子走不通，规则不清就比较，省略条件扩大范围，视觉说错关系，结尾增加新主张，引用不支持旁白。反复否定、冗余提醒或虚设误解挤占正文时删减；不将没有贯穿案例当缺陷。

给出 PASS/FAIL、定位、证据与最小修复建议，由原作者修复并复审受影响部分；不让 reviewer 默改、不靠随机重跑碰 PASS。另对实际渲染产物逐 beat/逐 cue 检查视觉与叙述；只有真的检查过才能记 GO。不存在的视觉或 harness 项记 N/A。

## 观察来源与边界

继承的上游记录称，曾通过 CDP 抽样观察李沐《Anthropic LLM 论文精读·51》的章节、页面和视觉节奏：

| 时间 | 章节 |
|---|---|
| 00:00 | 前言 |
| 06:15 | 标题、作者、摘要 |
| 09:34 | 导言 |
| 23:25 | 数据 |
| 34:45 | 偏好模型 |
| 44:09 | RLHF |
| 58:18 | 拓展 |
| 60:45 | 总结 |

可借鉴的是先建立问题、把主要篇幅留给数据/机制/关键结果、最后短收束的教学重心，不是固定时长比例。记录注明当时无可导出 caption track；它不支持逐字讲稿或个人语气复刻，也不代表本次重新观看或独立核验该视频。
