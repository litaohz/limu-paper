# limu-paper

**把论文讲成读者能亲自走通的认知路径。**

一份面向 Codex、Hermes 等支持 `SKILL.md` 的 Agent 环境的论文讲解 skill。借鉴李沐论文精读的教学组织：先理解研究问题和已有路线，再讲设计理由、机制与实验，把结论放回证据和适用条件里。

## 三种用法

- **局部问答**：卡在一个公式、定义或机制时，先解决当前问题，不展开成整篇报告。
- **完整精读 / 讲稿**：沿研究问题组织全文，讲清背景、相关工作、方法、实验和结论。
- **交互走读**：一次讲通一个机制、原题或结果，沿着你的追问继续。

## 五步教学方法

1. **建立研究问题**：从 Introduction 和 Related Work 说明前人做到哪、缺口是什么、本文改变了哪一步。
2. **补齐必要定义**：讲清输入输出、组件、任务、对照与指标，让后面的机制和结果有明确含义。
3. **解释设计与机制**：说明为什么这样设计；必要时用一个局部例子追踪输入、状态、组件交互和输出。
4. **连接结果与解释**：先交代比较规则，再说明观测支持什么、解释的边界在哪里。
5. **回答开场问题**：收束有证据支持的结论、成立条件和仍未知的部分。

另外，skill 对原文核对、表达方式和审阅提出要求：事实是否有支持，以及读者是否真正理解，分别检查。

## 安装

```bash
git clone https://github.com/litaohz/limu-paper.git
```

将得到的 **`limu-paper` 整个目录**放入你所用 Agent 的技能目录，保持 `SKILL.md` 与 `references/` 的相对位置不变。不同工具的技能目录和加载方式不同，按各自说明启用即可。

也可以在一次会话中，让 Agent 读取本仓库的 `SKILL.md`，按其中规则处理你提供的论文。

本仓库只有 Markdown 指令与参考文件，无需安装 Python/Node 依赖，不附带模型、API key 或论文下载器。论文读取、检索、计算和独立审阅能力由你的 Agent 环境提供。

## 使用示例

**完整精读**

```text
用 limu-paper 带我精读这篇论文：[论文链接或 PDF]。
讲清研究问题、已有路线、设计理由、机制和实验，并给关键原文定位。
```

**局部问题**

```text
用 limu-paper 解释这篇论文里的这个公式：[论文与公式位置]。
先说明符号和假设，再用一个可计算的小例子走通，不需要重讲整篇。
```

**边读边讨论**

```text
用 limu-paper 和我交互走读这篇论文：[论文链接或 PDF]。
先讲清研究问题和已有方法，我们再沿我的追问深入。
```

## 文件结构

```text
limu-paper/
├── SKILL.md
├── references/
│   ├── benchmark-reading.md
│   └── visual-storytelling.md
├── README.md
├── LICENSE
└── .gitignore
```

- [`SKILL.md`](SKILL.md)：使用范围、原文边界、五步教学、表达和审阅要求。
- [`benchmark-reading.md`](references/benchmark-reading.md)：需要解释评测时，沿一道真实原题走到评分，再理解主要成绩及其范围。
- [`visual-storytelling.md`](references/visual-storytelling.md)：制作视频讲稿、互动故事或视觉讲解时按需使用。

主 skill 可独立使用；`paper-reading` 是可选的配套入口，不是必装依赖。两份参考按任务加载，不需要在每次局部问答中全部展开。
